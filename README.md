# One Emoji, One Dream Vacation

Entry for the make.fun competition
`u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35`.

## Entry

One emoji: 🛖 — a tropical hut, an overwater bungalow on a quiet
lagoon. A single wordless postcard for a dream vacation: specific,
vivid at a glance, and instantly readable across cultures.

## How it works

`main.py` (Python stdlib only) writes exactly that one emoji, with no
trailing newline, to the absolute path `/output/entry.txt`.
